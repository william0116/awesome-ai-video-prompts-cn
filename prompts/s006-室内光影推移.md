# 室内光影推移

- **分类**：3D 场景
- **标签**：`three.js` `室内` `光影`
- **难度**：★★★☆
- **成片时长**：24 秒循环

> 阳光从窗外扫过房间，影子随时间缓慢移动

## Prompt

```
用 Three.js 做一个 24 秒循环的室内光影推移场景，画面 1920×1080。

房间：一个 8×5×3 的盒子（内表面朝里），墙面 #EDE6DA，地板 #C8B79B，用不同的 roughness 区分（墙 0.9，地板 0.5）。

家具（全部用基础几何体拼，不加载模型）：
- 一张桌子：桌面 2×0.08×0.9（#8B6F4E），四条腿 0.08×0.7×0.08。
- 一把椅子：座面 + 靠背 + 四条腿。
- 一个花瓶：CylinderGeometry，上宽下窄，颜色 #B05C3C。
- 窗户：在右墙上开一个 2.4×1.6 的洞（用三个 Box 拼墙留出开口），窗外用一个亮面片 #FFF6E0 充当天空光。

光照与光影：
- 一盏 DirectionalLight 从窗外角度射入，光色 #FFD9A0，强度 2.2，开启 castShadow，shadowMap 用 PCFSoft，mapSize 2048。
- 环境光 #A8B8D0，强度 0.35，模拟天空漫反射。
- 时间参数 t（0-1，24 秒循环）驱动平行光的方位角从 15 度转到 75 度，模拟太阳从清晨到傍晚的移动。

动效：光斑在桌面和地板上缓慢扫过（这是整个片子的主角），影子的边缘随光的角度变长、变软。地面上加一层极淡的尘埃粒子（500 个，大小 0.01，透明度 0.15）在光束中缓慢飘动。

要求：three.js 实现，必须开启阴影，禁止外部模型与贴图，所有材质用代码定义。
```

## 调参提示

这条最考验阴影参数。shadow.bias 设成 -0.0005、normalBias 设成 0.02 基本能消除阴影痤疮，不然地板上会出现条纹噪点。
