# 玻璃拟态卡片瀑布

- **分类**：动效图形
- **标签**：`css` `glassmorphism` `竖版`
- **难度**：★★☆☆
- **成片时长**：7 秒

> 9 张毛玻璃卡片依次落位，彩色光斑在背后缓慢漂移

## Prompt

```
用 HTML + CSS 做一个 7 秒的玻璃拟态卡片瀑布动画，画面 1080×1350（竖版，适配短视频）。

背景层：纯 CSS 生成三团彩色光斑 —— 三个 400px 的圆形，radial-gradient 分别用 #FF6B6B、#4ECDC4、#FFE66D，加 80px blur，在 #12121A 的暗底上以 12 秒周期缓慢漂移（各自不同的运动轨迹，形成互相穿插的色块）。

前景层：9 张卡片依次从画面顶部落入，间隔 0.12 秒。每张卡片 260×170，圆角 20px，背景 rgba(255,255,255,0.08)，backdrop-filter: blur(14px)，1px 描边 rgba(255,255,255,0.18)，顶部内阴影 rgba(255,255,255,0.25) 1px 制造玻璃高光。

落位动画：下落速度用 cubic-bezier(0.22, 1, 0.36, 1)，落地时有 6px 的过冲回弹，每张卡片带 -2° ~ 2° 的随机初始旋转并在落定后归零。

落定后，每张卡片内部出现一行模拟数据文字（如「转化率 32.4%」「活跃 1,280」），文字从 0 到 1 逐字显现，间隔 0.03 秒。

要求：主体用 CSS 动画完成，JS 只负责控制卡片出现顺序。backdrop-filter 不允许用切图或预设 PNG 替代。
```

## 调参提示

backdrop-filter 在这种叠层场景下很吃 GPU，9 张同时存在时可能掉帧。降到 6 张或把 blur 从 14px 提到 10px 会明显改善。
