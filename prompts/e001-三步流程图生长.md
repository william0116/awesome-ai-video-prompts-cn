# 三步流程图生长

- **分类**：解说与信息图
- **标签**：`svg` `流程图` `讲解`
- **难度**：★☆☆☆
- **成片时长**：6 秒

> 节点逐个长出、连线逐段绘制，最基础也最通用的解说动画

## Prompt

```
用 HTML + 内联 SVG + CSS 做一个 6 秒的三步流程图生长动画，画面 1920×1080。

三个步骤节点横向排列，各为 320×120 的圆角矩形（圆角 16px），文字分别是「输入需求」「模型生成」「人工校验」。配色：节点底 #FFFFFF、描边 #E7DFD5、主文字 #2E2A26、序号圆点用 #C2662F。

生长顺序（严格串行）：
- 0.0 ~ 0.6s：第一个节点从 0.92 倍缩放淡入，描边从 0 开始「画」出来（用 stroke-dasharray + stroke-dashoffset 动画）。
- 0.6 ~ 1.2s：节点之间的连接线从左端向右逐段延伸（同样用 dashoffset），线末端带一个箭头。
- 1.2 ~ 1.8s：第二个节点按同样方式出现。
- 依此类推，每 1.2 秒推进一步，总时长正好 6 秒。

细节：每个节点出现时，左上角的序号圆点（直径 36px，底色 #C2662F，白色数字）做一个 1.15 倍的弹跳；节点内文字延迟 0.15 秒后淡入。

背景 #FAF7F3（浅色，适合直接贴进 PPT 或公众号）。

要求：纯 SVG + CSS 动画，不用 JS 时间轴库，不用外部字体，矢量清晰可放大。
```

## 调参提示

这条是全库复用率最高的模板——把三个节点换成五个、改配色为深色，就能套到任何「A 到 B 到 C」的说明场景。
