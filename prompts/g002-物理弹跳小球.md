# 物理弹跳小球

- **分类**：游戏与交互
- **标签**：`canvas` `物理` `弹性`
- **难度**：★★☆☆
- **成片时长**：可玩

> 点击生成小球，重力与弹性碰撞，纯粹的物理玩具

## Prompt

```
用 Canvas 2D 做一个可交互的物理弹跳玩具，画布 1000×1000，背景 #0B0E14。

核心：点击或拖拽时在鼠标位置生成一个小球（半径 14-26 随机，颜色从 #C2662F / #3D7BA3 / #3F8A6E / #6F68AD / #B0831F 中随机取），最多同时存在 40 个，超出后移除最早的。

物理：
- 重力 g = 0.55 px/frame²。
- 球与地面、左右墙碰撞时，法向速度乘以恢复系数 0.82（竖直方向）和 0.95（水平方向）。
- 球与球之间做简单的弹性碰撞（质量按半径平方比），只在两者距离小于半径和时处理，允许轻微重叠，不做位置修正——这样反而更自然。
- 地面摩擦：每次触地水平速度乘 0.98。
- 球在速度极低（< 0.3）且贴地时进入静止状态，不再计算，以保性能。

视觉：
- 每个球画一圈半透明的外发光（shadowBlur 12，同色）。
- 球体内部做一个从左上到右下的径向渐变（高光偏白），让它看起来是立体的。
- 运动时留下极短的拖尾（画前 3 帧的位置，透明度 0.15 / 0.08 / 0.04）。
- 地面上画一条 4px 的亮线，球触地时亮线做一个 0.15 秒的亮度脉冲。

要求：单文件 HTML，不用物理引擎库，自己写积分（建议用半隐式欧拉），稳定 60fps。
```

## 调参提示

半隐式欧拉（先更新速度再更新位置）比显式欧拉稳定得多，同样的重力参数下球不会越弹越高。这是这类玩具最容易忽略的一行代码。
