# 等距网格数据流

- **分类**：动效图形
- **标签**：`svg` `等距视角` `数据管道`
- **难度**：★★★☆
- **成片时长**：8 秒循环

> 手写三维投影的等距管网，光点沿路径流动点亮节点

## Prompt

```
用内联 SVG + 原生 JS 做一个等距视角的数据管道动画，画布 1080×1080，8 秒循环。

场景定义：等距投影变换为 rotateX(60deg) rotateZ(45deg)。布置 3×3 共 9 个立方体节点，边长 120px，间距 200px。每个立方体由三个面拼成（顶面 / 左面 / 右面），统一取自靛蓝 #3D5AFE 的三个明度：#5C77FF、#2A44D6、#1B2A99。

连线：按 S 形路径把 9 个节点串成一条单向管道（折线，stroke-width 6，圆角连接），未点亮时为 rgba(255,255,255,0.10)。

动效：每 1 秒有一个半径 7px 的高亮光点（#7DF9FF，带 gaussian 发光滤镜）沿路径匀速前进。光点经过的管道段在 0.3 秒内由 0.10 透明度升到 0.9 再回落；光点到达立方体时，该立方体做 6px 的垂直弹起和 1.04 倍缩放脉冲，缓动 cubic-bezier(0.34, 1.56, 0.64, 1)。

背景 #0B0E14，加一层等距地面网格（间距 120px，线宽 1，透明度 0.05）。

要求：三维坐标必须自己在 JS 里做投影计算得到 SVG path，不得使用 three.js 或任何 3D 库，不引用外部字体。
```

## 调参提示

这套等距坐标系可以直接复用到「架构图动画」——把立方体换成服务节点，管道换成调用链，就是一张会动的系统架构图。
