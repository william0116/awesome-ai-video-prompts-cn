# 极简贪吃蛇

- **分类**：游戏与交互
- **标签**：`canvas` `游戏` `网格`
- **难度**：★★☆☆
- **成片时长**：可玩

> 去掉一切装饰的贪吃蛇，移动带插值平滑，死亡有溶解效果

## Prompt

```
用 Canvas 2D 做一个极简风格的贪吃蛇，画布 800×800，网格 20×20（每格 40px），背景 #0B0E14。

规则：方向键或 WASD 控制，吃到食物长度 +1 分数 +10，撞墙或撞到自己则游戏结束。

视觉（刻意做减法）：
- 蛇身：每节画一个 36×36 的圆角方块（圆角 10px），头部 #4FD1C5，身体从 #3D7BA3 到 #2A5A7A 依次渐暗，节与节之间留 4px 间隙。
- 食物：一个 20px 的圆，颜色 #C2662F，带 1.15 倍的呼吸脉动（周期 1 秒）。
- 网格：极淡的 1px 网格线 rgba(255,255,255,0.03)。

关键细节 —— 移动插值：格子逻辑按固定 130ms 一跳，但渲染时每一节的位置在「上一格」和「当前格」之间做线性插值（进度 = 距上次跳格的毫秒数 / 130）。这样蛇是顺滑移动的，而不是一格一格地闪。这是这条 prompt 的核心要求。

食物被吃时：食物位置炸开 12 个小方块粒子，0.3 秒内消散。

死亡：蛇身从尾到头依次「溶解」——每节延迟 30ms 变成半透明并缩小到 0，全部消失后画面中央淡入「GAME OVER」和当前分数，按 R 重开。

要求：单文件 HTML，不使用游戏引擎，插值必须在渲染层做而不是改变逻辑步长。
```

## 调参提示

「格子逻辑 + 渲染插值」这个模式可以套到任何网格移动的游戏上（推箱子、走迷宫），是低代码做顺滑手感的标准解法。
