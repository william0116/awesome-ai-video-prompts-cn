# 漏斗转化过程

- **分类**：解说与信息图
- **标签**：`svg` `漏斗` `转化率`
- **难度**：★★☆☆
- **成片时长**：5 秒

> 用户从上到下逐级流失，直观呈现每一步损耗

## Prompt

```
用 SVG 做一个 5 秒的漏斗转化动画，画面 1080×1350（竖版），背景 #FAF7F3。

结构：4 级漏斗，从上到下宽度依次为 800 / 600 / 420 / 260，每级高度 180px，梯形拼接（用 SVG polygon）。四级颜色从 #C2662F 逐级变浅到 #E8C9B0（同色系明度递减，暗示「越来越少」）。

标签：每级右侧标注「曝光 10,000」「点击 3,200」「注册 860」「付费 128」，以及左侧标注转化率「32%」「27%」「15%」。标签字号 28px，颜色 #2E2A26。

动画顺序（每级 0.9 秒）：
1. 该级梯形从顶部以 scaleY 0 → 1 生长（transform-origin 为顶部），并伴随轻微的下落位移。
2. 生长完成后，右侧数字从上一级的值滚动到本级的值（0.4 秒）。
3. 左侧转化率以「32%」形式淡入，并有一个 40px 的横向划入动画。

细节：每级之间用 2px 的间隙分隔，间隙中放一条虚线箭头向下。全部完成后，最底部加一行总结文字「最终转化率 1.28%」，字号 32px 加粗 #C2662F。

要求：纯 SVG + CSS 动画实现，不使用外部库；各级的数据必须是独立的可替换文本节点，方便改成自己的数据。
```

## 调参提示

漏斗的说服力全在「数字差得有多狠」。如果你的数据差得不够狠，就加上绝对值（10,000 → 128）而不是只放百分比。
