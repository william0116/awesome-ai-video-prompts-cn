# 故障艺术图片切换

- **分类**：动效图形
- **标签**：`canvas` `glitch` `像素操作`
- **难度**：★★★☆
- **成片时长**：4 秒循环

> RGB 通道分离 + 横条错位 + 扫描线，三段式故障切换

## Prompt

```
用 Canvas 2D 做一个 4 秒循环的 glitch 故障切换动画，画面 1920×1080。

内容层：用 canvas fillText 画抽象字「RE」，字体 380px bold，分三色叠加——品红 #FF3B5C、青 #00E5FF、近黑 #17171B，三层错开 4px 形成轻微的色差基态。

故障切换发生在第 1.2s、2.6s、3.6s 三个时间点，每次持续 0.45 秒，期间叠加以下四层效果：
1. RGB 通道分离：红通道整体左移 12px，青通道右移 12px，用逐像素读取 ImageData 后重绘实现。
2. 水平切片错位：把画面切成 18 条随机高度的横条，随机挑 6 条做 ±40px 的水平偏移。
3. 扫描线：叠加 2px 间隔、rgba(0,0,0,0.35) 的横纹。
4. 随机矩形噪点：3 帧内每帧生成 8 个随机位置、随机大小的白色块，rgba(255,255,255,0.6)。

静止段必须完全干净（无残留偏移、无扫描线）。

要求：所有效果通过 canvas 像素操作或分层重绘实现，禁止用 CSS filter 或 mix-blend-mode 作弊，禁止引入外部库。
```

## 调参提示

第 1 层通道分离是这个效果的核心，也最贵——1920×1080 逐像素处理在低端机上会掉帧，建议把处理区域限制在文字包围盒内而不是全屏。
