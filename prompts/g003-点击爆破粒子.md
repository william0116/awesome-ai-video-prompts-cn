# 点击爆破粒子

- **分类**：游戏与交互
- **标签**：`canvas` `粒子` `交互`
- **难度**：★☆☆☆
- **成片时长**：可玩

> 点击任意位置炸开一簇粒子，色彩与力度随机，纯解压

## Prompt

```
用 Canvas 2D 做一个点击爆破的粒子玩具，画布铺满窗口，背景 #0A0A0F。

交互：在任意位置按下鼠标（或触摸）时，该点生成 60 个粒子，向四周炸开。

粒子参数（每个粒子独立随机）：
- 初速度：方向 0-2π，速度 3-14 px/frame。
- 半径：1.5-5 px。
- 生命：0.6-1.2 秒。
- 颜色：从一个调色板随机取——#FF6B6B、#FFD93D、#6BCB77、#4D96FF、#B983FF、#FF9F45。
- 每个粒子受轻微重力（0.06）和空气阻力（每帧速度乘 0.965）。

视觉：粒子用发光圆点绘制（shadowBlur 8，同色）；粒子透明度随生命线性衰减；粒子半径随生命从 1 倍缩到 0.3 倍。

额外反馈：
- 点击位置先出现一个快速扩散的圆环（半径 0 → 90，0.3 秒，描边 2px，透明度 0.8 → 0）。
- 连续快速点击（间隔 < 0.15 秒）时，每次爆破的粒子数 +10，上限 120，形成「越点越炸」的爽感。
- 画面加一层极淡的残留拖影（每帧用 rgba(10,10,15,0.18) 覆盖而非 clearRect），让运动有尾迹。

要求：单文件 HTML，粒子总数上限 3000，超出后淘汰最旧的，保证 60fps。
```

## 调参提示

用半透明矩形覆盖代替 clearRect 制造拖影，是这类效果最省性能的做法——一行代码换一个量级的质感提升。
