# 时间轴演化

- **分类**：解说与信息图
- **标签**：`svg` `时间轴` `历史讲解`
- **难度**：★★☆☆
- **成片时长**：8 秒

> 横向时间轴逐段点亮，适合讲「从过去到现在」

## Prompt

```
用 HTML + SVG 做一个 8 秒的横向时间轴动画，画面 1920×1080，浅色底 #FAF7F3。

结构：一条贯穿全宽的横轴（y 居中，线宽 2px，颜色 #E7DFD5），轴上有 5 个时间点，均匀分布。每个时间点对应一个年份标签（2019 / 2021 / 2023 / 2025 / 2026）和一个卡片（位于轴的上下交替摆放，卡片 280×140，圆角 12px，白底，1px 描边 #E7DFD5，带极淡投影）。

动画：轴线从左端向右逐段绘制（stroke-dashoffset，2 秒走完）。每经过一个时间点，该点点亮为实心 #C2662F 并放大 1.3 倍，同时对应卡片以 0.96 倍缩放淡入并上浮 12px 落位，随后卡片内的标题和一行说明文字依次淡入。

节奏：每 1.4 秒推进一个时间点，五点按顺序点亮，全部完成后停留 0.5 秒。

细节：已点亮的时间点与轴线保持 #C2662F，未点亮的保持 #E7DFD5，形成「历史走到哪里」的视觉进度。

要求：纯 SVG + CSS 动画，卡片内容可直接改文本复用，不引入外部库和网络字体。
```

## 调参提示

讲技术发展史特别好用。注意卡片上下交替是为了避免横向拥挤——如果文案超过 40 字，卡片要么加高要么改成只放标题。
