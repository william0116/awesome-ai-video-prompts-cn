# 粒子聚合成汉字

- **分类**：动效图形
- **标签**：`canvas` `粒子` `文字动画`
- **难度**：★★☆☆
- **成片时长**：5 秒循环

> 3000 个粒子从随机散布收敛成字形，冷暖色过渡

## Prompt

```
用 Canvas 2D 做一个 5 秒循环的粒子成型动画，画面 1080×1080。

目标字形是「算」。实现方式：先用离屏 canvas 以 220px bold 黑体绘制该字，再逐像素采样得到粒子目标坐标，采样步长 3px，控制在 3000 个点左右。

初始化：3000 个粒子随机散布满屏，颜色 #4FD1C5，透明度 0.35，带 shadowBlur 6 的轻微发光。

动画分三段：
- 0 ~ 1.0s：粒子随机游走（速度 ±30px/s），像悬浮的尘埃。
- 1.0 ~ 2.2s：每颗粒子用 easeInOutCubic 向自己的目标点收敛，到达时间错开 0-0.4 秒随机，形成「先后落位」的层次感。
- 2.2 ~ 5.0s：粒子在目标位上做 ±0.8px 的呼吸抖动（频率 1.2Hz），同时整体颜色从 #4FD1C5 平滑过渡到暖白 #F5F1EA。

背景 #0D1117，铺一层 32px 间距、1px 宽、rgba(255,255,255,0.03) 的细网格。

要求：requestAnimationFrame 驱动，每帧只重绘一次，不引入外部库，粒子数量不得超过 3500 以保证 60fps。
```

## 调参提示

采样步长是清晰度和性能的唯一天平：3px 清晰但吃性能，5px 更稳但字形会散。移动端建议直接改 5px。
