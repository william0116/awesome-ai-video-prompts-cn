# 打砖块变体

- **分类**：游戏与交互
- **标签**：`canvas` `游戏` `物理反弹`
- **难度**：★★☆☆
- **成片时长**：可玩

> 经典打砖块，砖块被击中时有粒子爆开，比分实时更新

## Prompt

```
用 Canvas 2D 做一个可直接游玩的打砖块游戏，画布 900×1200（竖版，适合手机录屏）。

元素：
- 挡板：宽 140、高 14，圆角 7，颜色 #F5F1EA，跟随鼠标或触摸横向移动，位置做 0.25 的插值平滑。
- 球：半径 10，颜色 #C2662F，初速度 (4, -5.5)，每帧速度大小恒定，碰撞时反射。
- 砖块：6 行 × 8 列，砖块 100×36，间距 8，从第 1 行到第 6 行颜色依次 #FF6B6B / #FFA94D / #FFD43B / #69DB7C / #4DABF7 / #9775FA。不做多段血量，一次击碎。

物理规则：
- 球与挡板碰撞时，反弹角度根据击中位置偏移计算（击中挡板左三分之一向左偏，右三分之一向右偏，最大偏角 60 度）。
- 球与砖块碰撞用最近点法判定，避免球速快时穿透。
- 球碰到左右墙和顶部反弹，掉出底部则游戏结束。

反馈：
- 砖块被击碎时生成 8 个粒子（随机方向，速度 2-5，存在 0.4 秒后消失，颜色取砖块本身的颜色）。
- 击败一个砖块分数 +10，左上角显示分数，字号 32px，等宽字体。
- 全部击碎后画面中央显示「通关」，并允许空格键重开。

背景：深色 #0B0E14，砖块区域加极淡的网格。

要求：单文件 HTML，requestAnimationFrame 驱动，用固定时间步长（60Hz）计算物理，不使用任何游戏引擎或外部库。
```

## 调参提示

球速快时穿透砖块是打砖块的经典 bug。解法是每帧把球的位置细分成若干小步逐步检测，而不是一帧只判一次。
