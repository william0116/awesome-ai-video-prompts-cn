# 液态金属文字开场

- **分类**：动效图形
- **标签**：`canvas` `svg` `文字动画` `金属质感`
- **难度**：★★☆☆
- **成片时长**：6 秒循环

> 铬反射渐变 + 高光扫过 + 水银边缘扰动，适合做 LOGO 开场

## Prompt

```
用 HTML + CSS + Canvas 做一个 6 秒循环的液态金属文字开场动画，画面 1920×1080。

屏幕中央出现「未来」两个汉字，字形用 SVG path 手写描边，填充使用线性渐变模拟铬反射：色标依次为 #E8E8EA → #8B8B93 → #FFFFFF → #6E6E76，角度 -30deg，并让渐变角度随时间在 -35deg ~ -25deg 之间缓慢往复（周期 4 秒）。

文字出现后 0.3 秒，从左到右有一道高光扫过：用 clip-path 裁出一个倾斜 20 度的白色窄条（宽 120px，透明度 0.85），在 0.6 秒内匀速扫过全宽，扫完立即移除。

随后 1.5 秒内，字体边缘像水银一样轻微扰动：把每个字转成离屏 canvas 采样，每隔 4px 取一个点，给每个点叠加 sin 噪声位移，振幅 1.5px，频率在 0.6-1.2Hz 之间随机，扰动结束后缓动归位。

背景纯黑 #0A0A0B，叠加 0.85 的径向暗角。整体 loop 无缝衔接。

要求：稳定 60fps，不引入任何外部库、外部字体和图片，所有质感必须由代码绘制。
```

## 调参提示

把「未来」换成你的品牌名时，注意字形笔画数——笔画过少（如英文单字）金属反光会看不出层次，建议至少 4 个汉字或改用粗体字母组合。
