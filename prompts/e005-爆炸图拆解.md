# 爆炸图拆解

- **分类**：解说与信息图
- **标签**：`css-3d` `拆解图` `产品讲解`
- **难度**：★★★☆
- **成片时长**：6 秒

> 层次沿 Z 轴依次分离，讲清一个复杂东西由什么组成

## Prompt

```
用 HTML + CSS 3D（transform-style: preserve-3d）做一个 6 秒的爆炸拆解动画，画面 1920×1080，背景采用 #0E1117 径向渐变到 #05070A。

主体：用纯 CSS 拼一个「三层结构」的抽象图形，三块 300×300×40 的扁平板（分别用三个 div 通过 rotateX / translateZ 模拟薄板），初始时紧密叠在一起。三块板配色：顶板 #4FD1C5、中板 #3D7BA3、底板 #6F68AD，均带 1px 白色 0.2 透明度描边。

动画：镜头先以 rotateX(55deg) rotateZ(-25deg) 呈现一个斜俯视角（用 CSS 变量控制，开场 1 秒内从 0 度转到这个角度）。然后从 1.0 秒开始，三块板沿各自法线方向依次分离，间隔 0.5 秒，最终每块间距 180px。分离过程中每块板旁边淡入一行标签文字（如「感知层」「决策层」「执行层」），标签用细线连接到板边。

细节：分离完成后整体做极缓慢的自转（15 秒一圈），并用 3 组不同衰减的投影（box-shadow 多层）制造悬浮感。板与板之间的空隙用极淡的半透明连接线示意「它们原本是一体的」。

要求：不引入 three.js，纯 CSS 3D 变换实现，所有尺寸用 CSS 变量以便整体缩放。
```

## 调参提示

纯 CSS 3D 做不超过 5 层的东西完全够用，超过就要上 Three.js 了。这条的复用场景：产品架构、技术栈分层、课程大纲拆解。
