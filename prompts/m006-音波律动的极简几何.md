# 音波律动的极简几何

- **分类**：动效图形
- **标签**：`canvas` `几何` `节拍模拟`
- **难度**：★★☆☆
- **成片时长**：5 秒循环

> 12 条放射状线条随节拍伸缩，不需要真实音频

## Prompt

```
用 Canvas 2D 做一个 5 秒循环的音频律动视觉，不需要接入真实音频，用数学函数模拟节拍，画面 1080×1080，背景 #08080A。

主体是一个正十二边形结构，由 12 条从中心向外放射的线条构成，角度均匀分布（每 30 度一条）。

长度公式：设 t 为当前时间，每 0.5 秒为一个 beat；对第 i 条线、当前 beat 开始时间 beatTime，长度 L = 120 + 260 × exp(-(t - beatTime) × 6) × (0.5 + 0.5 × sin(i × 1.7))。这样每条线的衰减相位不同，形成「波」而不是「齐射」。

线条样式：从中心 #F5F1EA 到端点 #C2662F 的线性渐变，stroke-width 4，端点 lineCap: round。

外圈叠加三层同心圆环，半径 200 / 280 / 360，描边 1px，透明度分别 0.12 / 0.08 / 0.05，每个 beat 到来时整体缩放到 1.03 倍并在 0.4 秒内回落。

最后叠一层 0.9 强度的径向暗角，中心透明、边缘 #000。

要求：稳定 60fps，不使用 Web Audio API，不引入外部库，所有数值写死在代码里以便调整。
```

## 调参提示

想接真实音乐时，把 sin 函数替换成 AnalyserNode 的 getByteFrequencyData 分频段取样即可，几何结构完全不用改。
