# 磁力场跟随

- **分类**：游戏与交互
- **标签**：`canvas` `交互` `粒子场`
- **难度**：★★☆☆
- **成片时长**：可玩

> 数百个粒子被鼠标吸引又排斥，移动鼠标即是创作

## Prompt

```
用 Canvas 2D 做一个鼠标磁力场粒子系统，画布铺满窗口，背景 #08080C。

粒子：预置 600 个粒子，初始随机分布，每个有位置、速度、一个随机的基础色（从 #4FD1C5 / #6F68AD / #3D7BA3 三色中取）。

力场规则（每帧对每个粒子计算）：
- 计算粒子到鼠标的距离 d。
- 当 d < 220 时，施加一个吸引力：加速度 = (220 - d) / 220 * 0.9，方向指向鼠标。
- 同时施加一个切向力（垂直于连线方向），强度为吸引力的 0.85 倍，方向由鼠标移动速度决定正负——这会让粒子绕着鼠标旋转而不是直接撞上去。
- 粒子之间不做碰撞（600 个两两计算太贵），改为施加一个极弱的全局斥力让它们不至于完全聚成一坨。
- 速度上限 6，每帧乘 0.94 阻力。

视觉：
- 粒子画成 2px 的点，透明度由速度决定（静止时 0.2，高速时 1.0）。
- 距离鼠标 60px 内的粒子半径放大到 3px 并偏白。
- 用一个 5000 长度的拖尾缓冲（存最近 40 帧的鼠标位置），画成一条极淡的线，让用户能看到自己的运动轨迹。
- 鼠标快速移动时，沿途生成短暂的冲击波环（最多同时 5 个）。

要求：单文件 HTML，鼠标离开窗口时力场平滑淡出（不能突然消失），保证 60fps。
```

## 调参提示

加切向力是这类「跟随」效果从廉价变成高级的分水岭。只有吸引力的话，粒子会糊成一团；加上切向力才有流体绕流的质感。
