# 抽象流体雕塑

- **分类**：3D 场景
- **标签**：`three.js` `shader` `流体`
- **难度**：★★★★
- **成片时长**：20 秒循环

> 用噪声着色器让一个球体持续变形，像活着的金属雕塑

## Prompt

```
用 Three.js + 自定义 ShaderMaterial 做一个 20 秒循环的抽象流体雕塑，画面 1080×1080。

几何：一个 IcosahedronGeometry，半径 3，细分级别 6（约 2 万面），这样顶点足够密才能做出流体形变。

顶点着色器：使用 3D simplex noise（噪声函数写在 shader 里，不引入外部库）。对每个顶点，计算沿法线方向的位移量：
offset = 0.28 * noise(position * 1.6 + vec3(t * 0.35)) + 0.14 * noise(position * 3.4 - vec3(t * 0.5));
最终 position += normal * offset。

片元着色器：做一个彩虹感的虹彩效果——用视线方向与法线的点积做菲涅尔项，边缘偏 #6F68AD，正面偏 #4FD1C5，中间过渡经过 #C8F5E9。再叠加一层极细的等高线（用 sin(位移量 * 40) 取阈值），颜色偏白，透明度 0.15，让形体有「线框扫描」的质感。

环境与光照：不依赖真实光源，全部在 shader 里计算。背景 #05070A 径向渐变，中心稍亮。

镜头：缓慢环绕（20 秒转 40 度），同时相机距离在 7.5 ~ 8.2 之间做极轻的呼吸。

要求：three.js 实现，所有形变必须发生在 GPU（顶点着色器），禁止在 JS 里逐帧修改顶点坐标。开抗锯齿。
```

## 调参提示

细分级别 6 是性能红线：再高一级面数翻四倍，中端笔记本就撑不住了。视觉上 6 级已经看不出多边形。
