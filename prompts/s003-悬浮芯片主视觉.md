# 悬浮芯片主视觉

- **分类**：3D 场景
- **标签**：`three.js` `产品主视觉` `发光`
- **难度**：★★★☆
- **成片时长**：15 秒循环

> 发光芯片悬浮旋转，接口处有光流进出，适合科技产品片头

## Prompt

```
用 Three.js 做一个 15 秒循环的科技主视觉：一块悬浮的芯片在暗场中缓慢旋转，画面 1920×1080。

芯片本体：一个 2.4×2.4×0.12 的方板（BoxGeometry），材质用 MeshStandardMaterial，颜色 #12203A，金属度 0.9，粗糙度 0.25。表面用代码绘制细节：在外层再叠一个同尺寸的平面，用 CanvasTexture 画出电路的走线图案（细线 #2E6E8E，若干方形焊盘 #4FD1C5），作为自发光贴图叠加。

发光边缘：用一个略大的方框（EdgesGeometry + LineSegments）描出 #4FD1C5 的轮廓，透明度 0.8，加轻微脉动。

悬浮与旋转：芯片整体绕 Y 轴匀速旋转（15 秒一圈），同时做 ±0.15 单位的上下浮动（周期 4 秒）和 ±3 度的 X 轴摇摆。

接口光流：芯片四条边外侧各有 4 个小光点（共 16 个，球体，半径 0.04，#7DF9FF，emissive 强度 2），沿垂直于边缘的方向向外匀速移动，移出 1.5 单位后透明度归零并重置回边缘，形成数据进出的感觉。

环境：背景 #05070A 加 radial-gradient 暗角；一盏主光从右上打，一盏青色补光从左下打（#4FD1C5，强度 0.6）；地面不画，让芯片有「悬浮在虚空中」的感觉。

要求：three.js 实现，开抗锯齿，所有纹理用 Canvas 代码生成，禁止外部图片。
```

## 调参提示

这个结构换成任何「有接口的硬件」都成立——路由器、服务器、传感器。改的只是板子的长宽比和描边颜色。
