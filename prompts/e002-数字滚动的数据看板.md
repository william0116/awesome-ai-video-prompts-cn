# 数字滚动的数据看板

- **分类**：解说与信息图
- **标签**：`css` `数据可视化` `数字动画`
- **难度**：★★☆☆
- **成片时长**：5 秒

> 关键指标从 0 滚到目标值，配柱状图同步生长

## Prompt

```
用 HTML + CSS + 少量 JS 做一个 5 秒的数据看板动效，画面 1920×1080，深色背景 #0E1117。

布局：顶部一个标题条「本周核心指标」，下方 4 个指标卡横排（各 400×180，圆角 14px，背景 #161B22，1px 描边 #232A35），再下方一个横向柱状图区域。

数字滚动：4 个指标分别是 1,284 / 32.4% / ¥86.5万 / 7.8x。动画开始时数字从 0 用 easeOutExpo 滚到目标值，耗时 1.6 秒，滚动过程中千分位逗号和单位必须实时正确（不能出现「1,2,」这种中间态乱码）。数字字体用等宽字体，字号 56px，颜色 #F0F6FC。

柱状图：5 根柱子，宽度按数据比例（32% / 58% / 76% / 44% / 91%），从 0 宽度展开到目标值，延迟 0.8 秒开始，每根错开 0.1 秒，缓动 easeOutCubic。柱子用 #3D7BA3 到 #4FD1C5 的水平渐变，圆角右端。

细节：数字卡在滚动结束瞬间做一次 2px 的向上位移回弹；柱状图每根柱子末端有一个小数值标签淡入。

要求：数字滚动用 requestAnimationFrame 差值实现，禁止用 CSS counter 或直接切帧；不使用图表库。
```

## 调参提示

数字滚动的坑在单位：百分比和货币符号要在滚动时保持稳定位置，否则数字左右抖动会非常廉价。建议把单位和数字分成两个 span 定宽排版。
