# 分屏对比

- **分类**：解说与信息图
- **标签**：`css` `对比` `before-after`
- **难度**：★☆☆☆
- **成片时长**：5 秒

> 左右分屏逐项对比，中间分割线带推拉感

## Prompt

```
用 HTML + CSS 做一个 5 秒的左右分屏对比动画，画面 1920×1080。

布局：画面从中间竖切为左右两半，分割线宽 3px，颜色 #2E2A26。左侧标题「传统方式」，右侧标题「AI 方式」，标题为 36px 粗体，分别位于各自半屏顶部。

内容：左右各排 4 行条目（左：灰色调 #9C9288，右：暖橙 #C2662F），每行前面有一个小圆点。左右同一个序号的行在同一时刻出现，但入场方向相反——左行从左侧滑入 24px，右行从右侧滑入 24px，每行延迟 0.25 秒。

分割线：出现时从画面中线上端向下「生长」到底部（0.6 秒，scaleY 从 0 到 1，transform-origin 为 top），之后保持轻微呼吸（1.02 ~ 0.98 倍缩放，周期 3 秒）。

对比强调：当第 3 行（关键差异行）出现时，左右两行同时做一次高亮——底色闪一次 rgba(194,102,47,0.12)，0.4 秒消散。

背景：左侧 #F6F1EB，右侧 #FFFFFF，中间分割线是唯一的强对比元素。

要求：纯 CSS 实现，不用 JS 时间轴；两栏内容都可用纯文本替换，不需要图片。
```

## 调参提示

对比动画的说服力来自「同一时刻、同一行」的对照。如果左右行数不等，宁可留空行也不要错位，否则观众会去数还差几行。
